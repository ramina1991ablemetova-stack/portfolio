# Правила работы с учебным портфолио

- Использовать только чистые HTML, CSS и JavaScript.
- Сохранять существующие разделы сайта и их содержимое, если пользователь прямо не попросил изменить или удалить их.
- Не устанавливать пакеты и зависимости, не использовать фреймворки и инструменты сборки.
- Не использовать Git и не выполнять команды Git.
- Не подключать API и внешние сервисы.
- Не публиковать сайт и не выполнять развёртывание.
- Не добавлять реальные персональные, контактные, учётные или другие конфиденциальные данные. Для примеров использовать вымышленные данные и явные заглушки.
- После каждой правки перечислять внесённые изменения.
- Честно указывать выполненные проверки и их результат. Если проверка не выполнялась, прямо сообщать об этом; не утверждать, что сайт проверен в браузере, если он не открывался.
