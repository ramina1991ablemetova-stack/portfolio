# Учебное портфолио

Цель проекта — создать простой сайт-портфолио для практики HTML, CSS и JavaScript и демонстрации учебных работ. Используйте только вымышленные данные и учебные примеры.

## Файлы сайта

- `index.html` — структура страницы, разделы портфолио и содержимое.
- `style.css` — оформление сайта и адаптация к разным размерам экрана.
- `script.js` — интерактивное поведение страницы.

## Как открыть сайт

Сохраните три файла сайта в одной папке. Откройте `index.html` двойным щелчком или через команду «Открыть файл» в браузере. Установка пакетов, сборка и сервер не нужны.
